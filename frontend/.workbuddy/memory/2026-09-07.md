## 第八轮：管理控制台 v6/v7 flex 链路根因修复

用户截图中虽然 demo-foot 已贴主图面板底部，但 **demo-lib 与 demo-foot 之间仍有 ~150px 大段空白**——根因是 demo-lib 没撑开 prod-empty 容器剩余空间。

### 根因诊断
- demo-foot 原嵌套在 demo-lib 内 → margin-top: auto 只在 demo-lib 内生效 → 没贴 panel 底部
- v5/v6 即使设了 align-items: stretch，但 CSS Grid 默认 stretch 在某些 grid item 内 flex 链路下不生效
- demo-lib 没设 flex:1 → 占据自己内容高度，留出大段空白

### v6 修复
- 把 `demo-foot` 从 `demo-lib` 内提升为 `prod-empty` 的直接子项（demo-lib 之后）
- 让 `margin-top: auto` 真正推到 panel 底部

### v7 终极修复（flex 链路完整化）
```css
.top-grid > .panel {
  display: flex; flex-direction: column;
  height: 100%; min-height: 0;   /* 强制 stretch 等高 */
}
.top-grid > .panel > .phead { flex-shrink: 0; }  /* 标题不缩 */

.prod-empty {
  flex: 1 1 auto; min-height: 0;  /* 撑开 panel 剩余空间 */
}
.demo-lib {
  flex: 1 1 auto; display: flex; flex-direction: column;
  min-height: 0;                  /* 撑开 prod-empty 剩余空间 */
}

  flex: 1 1 auto; align-content: start;  /* 栅格撑开 */

```

### 关键教训
- flex 链路必须**逐层**显式声明 `flex: 1 1 auto` + `min-height: 0`，缺失任何一层会断链
- `min-height: 0` 是 flex item 在 column 容器内真正撑开的关键（flex 默认 min-height: auto 阻止压缩）
- CSS Grid `align-items: stretch` 与 flex column 子项结合时，需显式 `height: 100%` 才生效
