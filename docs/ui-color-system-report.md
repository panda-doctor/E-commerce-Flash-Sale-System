# 暖色电商品牌视觉重构交付报告

> 范围：`frontend/`（React 18 + TypeScript + Vite + Tailwind 3.4）。
> 本轮为**品牌配色重构**：奶油暖白画布 + 红橙品牌色 + 深色页脚，品牌色参与 Hero、图片区、标签与主操作，而不只是给文字染色。
> 未改 API 契约、未改业务判定、未新增依赖、未伪造商品/活动/订单数据。

## 二、首页第一张卡片"整块纯红"的真实原因

不是 CSS 背景，也不是加载失败，而是**后端返回了退化图片**：

| 证据 | 结果 |
|---|---|
| `GET /api/products?page=1&pageSize=1` | 首件商品 `imageUrl = /uploads/202610/*.png` |
| 响应体 | `Content-Type: image/png`，文件仅 **68 字节** |
| PNG IHDR | **1 × 1 像素**，bitDepth 8，colorType 6 |
| 浏览器 canvas 取样 | `rgba(255, 0, 0, 255)` —— 不透明纯红 |
| 渲染链路 | `object-cover` 把 1×1 拉伸到整个 4:3 区域 → 看起来像"整块红色背景" |

**处理**：在 `ProductImage` 中增加退化素材保护——图片 `naturalWidth < 8 || naturalHeight < 8` 时按无图处理，展示统一的暖色占位块。真正的加载失败仍由 `onError` 处理，二者不混为一谈；没有用 CSS 覆盖去"遮住"问题。

## 三、最终配色令牌（唯一色源）

`frontend/tailwind.config.js` 定义，`src/styles/index.css` 通过 `theme()` 派生 CSS 变量；组件不写裸色值。

| 用途 | 令牌 | 色值 | 说明 |
|---|---|---|---|
| 页面画布 | `page.DEFAULT` | `#FFF7F0` | 奶油暖白，替代原来的灰白 |
| 内容表面 | `page.card` | `#FFFFFF` | 卡片、表单、详情 |
| 次级暖面 | `page.subtle` | `#FFF0E5` | 工具栏、chip、提示 |
| 主文字 | `ink.900` | `#24202A` | 略带暖调的近黑 |
| 次级文字 | `ink.600` | `#6B6470` | 描述、时间、库存 |
| 弱化文字 | `ink.400` | `#8A8490` | 仅占位符/图标/禁用 |
| 品牌红（大字价格） | `brand.DEFAULT` | `#E53935` | 秒杀价、价格强调 |
| 实心按钮红 | `brand.solid` | `#D32F2F` | 白字 4.98:1，达 AA |
| 深红（hover/小字） | `brand.dark` | `#C62828` | 浅红底小字 4.77:1 |
| 深红强调 | `brand.deep` | `#B71C1C` | Hero 渐变起点、active |
| 促销橙 / 珊瑚 | `brand.orange` / `brand.coral` | `#FF8A34` / `#FF6548` | 仅装饰、渐变、图标 |
| 浅红 / 浅橙 | `brand.soft` / `brand.cream` | `#FFE7E5` / `#FFF0E3` | 徽标、局部背景 |
| 边框 / 强边框 / 悬停 | `state.line` / `line-strong` / `hover` | `#F0E1DA` / `#E6D0C5` / `#FFC7B6` | 暖色发丝线 |
| 成功 / 警告 / 失败 | `state.*` | `#12724E` / `#9A5B08` / `#C42A1F` | 只表达真实业务状态 |
| 页脚 | `footer` | `#2A1B19` / `#F7E9E4` / `#C9B4AC` | 深暖收束 |

**Hero 渐变**：`linear-gradient(115deg,#B71C1C 0%,#C62828 48%,#E53935 76%,#FF6548 100%)`；所有正文放在 0–48% 深红一侧，保证白字对比度；右卡片为白色表面，不受渐变干扰。

## 四、颜色分布

- **约 60%**：奶油画布 + 白色卡片/表单/详情表面；
- **约 25%**：浅橙工具栏、浅红徽标、暖色图片占位、活动浅底；
- **约 15%**：品牌红实心按钮、秒杀价、折扣角标、Hero 渐变、页脚深色。

没有把商品卡做成不同底色，也没有整页铺红：品牌色集中在"首屏活动区 + 价格 + 主操作 + 页脚对比"。

## 六、落地清单

### 全局

- `tailwind.config.js`：暖色令牌、Hero/图片区渐变、三档暖阴影、页脚色、字号与 z-index。
- `styles/index.css`：`--color-*` 由令牌派生；`.card/.card-hover` 暖边框与暖阴影；`.section-title` 品牌短线；`.filter-pill(-active)` 品牌实心选中；`.notice` 暖色提示；全局 `prefers-reduced-motion` 降级；页面顶部一层极淡暖光。
- `ProductImage`：暖色占位（白色图标底 + 柔光斑）与 1×1 退化图片保护。
- `Button`：`bg-brand-solid` + 深红 hover/active；焦点环、loading、disabled 统一。
- `Badge`：浅红底深红字；状态色只给真实状态。
- `Input`：暖色边框 hover + 品牌色焦点环。
- `Pagination`：当前页品牌实心；`Toast`：白面 + 语义细边框；`EmptyState`：暖色图标底衬。

### 页面

| 页面 | 改动 |
|---|---|
| 首页 | 红橙渐变 Hero（装饰光斑 + 白色活动卡 + 真实倒计时）；白色工具栏（搜索/数量/刷新）；品牌短线分区标题；商品区 2/3/4 列 |
| 商品卡 | 方形图 + 暖色占位；浅红"限时秒杀"；折扣角标仅在优惠 ≥5% 时显示；"秒杀价"标签前置；深色标题、灰色原价、品牌红价格；秒杀 CTA 实心红、普通 CTA 白底暖 hover |
| 活动卡/列表 | 暖色倒计时胶囊、橙色渐变库存条、阶段徽章语义化；筛选胶囊品牌实心选中 + 真实计数 |
| 商品详情 | 主图限宽 460px + 暖色占位；活动区浅红底 + 品牌描边；阶段徽章与时间窗一致；秒杀按钮实心红 |
| 登录/注册 | 暖色卖点面板 + 白色表单；红色主按钮；错误统一危险语义 |
| 我的订单 | 奶油画布 + 白色订单卡；筛选品牌实心；状态徽章绿色语义；下单时间提升为次级色 |
| 页脚 | 深暖色三段式，与浅色内容形成明确收束 |
| 管理端 | 共享令牌但保持中性：去掉装饰红/蓝，仅保留主操作与选中态 |

### 数据与业务

- 首页活动判定沿用 `phaseOfItem`（时间窗），与活动列表、详情页统一；未改任何接口或库存/下单逻辑。
- 折扣角标、原价划线均基于真实字段计算；活动价不低于原价时隐藏划线价与折扣。

截图后继续修掉的问题：

1. 平板端 Hero 堆叠过高 → `md` 起双栏；
2. 平板商品区 2 列过疏 → `md` 起 3 列；
3. 极小价差被算成"0.2 折" → 优惠 <5% 不显示角标；

5. 首页右上角与倒计时重复 → 改为真实的"已抢 X%"；
6. 秒杀价标签排在原价之后 → 前置到价格前。
